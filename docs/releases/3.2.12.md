# sysPass 3.2.12

Security maintenance release for the sysPass 3.2 line. This release is an
in-place update for existing 3.2.11 installations and does not change the
database schema or encryption format.

## Security updates

- Update Guzzle from 6.5.8 to 7.15.5.
- Update guzzlehttp/psr7 from 1.9.0 to 2.13.1.
- Update guzzlehttp/promises from 1.5.1 to 2.5.3.
- Update phpseclib from 2.0.37 to 2.0.55.
- Update compatible Symfony polyfills.
- Guard the legacy `mb_ucfirst` helper against redeclaration by newer
  polyfills.

The production Composer dependency audit reports no known security
advisories at release preparation time.

## Compatibility

- PHP 7.4 remains the supported runtime for this maintenance release.
- Existing configuration and database volumes can be reused without a schema
  migration.
- A password record created and encrypted by the unmodified 3.2.11 container
  was successfully decrypted after installing the 3.2.12 dependency set.

## Verification

- Composer production audit: 0 advisories.
- PHPUnit Core suite: 1459 tests, 22239 assertions, 0 errors, 0 failures.
- Existing-installation login smoke test: passed.
- Guzzle-backed release-check endpoint smoke test: passed.
- 3.2.11 encrypted password upgrade fixture: passed.
